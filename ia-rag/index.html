Glosario Básico

LLM

Large Language Model. Modelo de lenguaje entrenado con grandes volúmenes de texto.

RAG

Retrieval-Augmented Generation. Combina búsqueda de documentos con generación de texto.

Prompt

Instrucción o pregunta que le das a un modelo de IA para obtener una respuesta.

Embedding

Representación numérica del significado de un texto para búsqueda semántica.

Temperatura

Parámetro que controla la creatividad vs. precisión en las respuestas del modelo.

Token

Unidad mínima de texto procesada por un LLM (palabra o parte de palabra).
